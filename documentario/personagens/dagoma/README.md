# Folha de personagem do Dagoma

Onde gerar, na ordem dos créditos:

1. **Firefly, modelo Nano Banana Pro** — cole `PROMPT_NANOBANANA.txt` e anexe até 6 fotos. Se o Firefly não oferecer 4K, gere no máximo disponível e amplie depois.
2. **Dreamina, modelo Seedream** — mesmo prompt; chame as fotos por número ("image 1", "image 2"). Escolha 4K se a opção aparecer.
3. **ChatGPT** — `PROMPT_CHATGPT.md`.
4. **Replicate (Nano Banana Pro 4K)** — só se os créditos acima acabarem: `documentario/scripts/folha_personagem.py`.

Fotos de referência: de 2 a 4, rosto nítido, corpo inteiro, com os cases dos toca-discos. Uso do rosto e do corpo só com autorização do Dagoma, registrada no Cronograma.
